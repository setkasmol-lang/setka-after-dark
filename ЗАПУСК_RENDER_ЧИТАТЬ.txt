SETKA AFTER DARK — подготовлено для бесплатного ТЕСТА через Render

1) Распакуйте этот архив на компьютер.
2) На https://github.com/ создайте репозиторий (New repository), желательно Private.
3) В репозитории выберите Add file -> Upload files и загрузите файлы И ПАПКУ static из распакованного архива.
   В корне репозитория должны находиться server.py и render.yaml, рядом папка static.
   НЕ добавляйте папку data, пароль администратора, файлы .db и настоящие телефоны гостей.
4) На https://dashboard.render.com/ войдите через GitHub.
5) Нажмите New -> Blueprint -> подключите репозиторий с render.yaml.
6) При создании Render попросит SETKA_ADMIN_CODE. Введите НОВЫЙ длинный приватный код, не используйте код из старой переписки.
7) Подтвердите бесплатный план Free. После успешного развертывания откройте предоставленный адрес https://...onrender.com
8) Админ-панель: https://...onrender.com/admin — введите установленный приватный код.

!!! ВНИМАНИЕ: Render Free удаляет локальные файлы SQLite при засыпании после 15 минут без трафика, рестарте или обновлении. Эта публикация ТОЛЬКО для визуального и функционального теста на вымышленных данных. НЕ ДЛЯ НАСТОЯЩИХ КЛИЕНТОВ!

Для реальной работы с номерами телефонов потребуется постоянная база и юридическое оформление обработки персональных данных. Даже публичный URL тестового сайта не делает его production-ready.

Если настроить Blueprint сложно, можно через New -> Web Service с:
- Build Command: echo "No dependencies to install"
- Start Command: python server.py
- Environment: HOST=0.0.0.0; SETKA_HTTPS=1; SETKA_ADMIN_CODE=<новый личный код>
- Instance Type: Free
