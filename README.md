# СЕТКА AFTER DARK — рабочий сайт с админ-панелью

Готовый минимальный сайт для программы клуба: 30 подтверждённых ночных покупок от 400 ₽, 30 подарков, главный мерч на 21-й отметке, платный пропуск 500 ₽.

## Как быстро запустить на компьютере

1. Нужен **Python 3.10+**. Никакие `pip install` не нужны.
2. Распакуйте ZIP в отдельную папку.
3. На Windows можно просто открыть **`START_WINDOWS.bat`** (после установки Python). На macOS/Linux — `./START_MAC_LINUX.sh`. Или откройте терминал в папке и запустите:

   ```bash
   python server.py
   ```

4. Откройте **http://127.0.0.1:8080** — сайт гостя.
5. Откройте **http://127.0.0.1:8080/admin** — админ-панель.
6. Код находится в приватном файле `data/admin_code.txt`. Если его нет, программа создаст его при первом запуске. Код можно заменить: остановите сервер, впишите новый длинный код в этот файл и перезапустите.

Данные сохраняются автоматически в `data/setka.db`. **Не удаляйте эту папку** — в ней база участников, покупок, отметок и выдачи призов. Регулярно делайте резервную копию папки, предварительно остановив сервер, либо используйте SQLite backup.

## Как пользоваться

- В панели администратора: **Новый участник** → ник, телефон, подтвердить оплату пропуска за 500 ₽.
- Открыть участника → проверить сумму и дату покупки → нажать **Подтвердить покупку +1 ночь**.
- После успешного подтверждения автоматически открывается следующая награда. Дополнительные призы автоматически открываются на отметках 7, 14, 21 и 30.
- Приз выдаётся отдельно кнопкой **Выдать** — так можно отличать «заработал» и «фактически забрал».
- Скопируйте персональную ссылку участника и отправьте ему. Он видит прогресс и награды **без доступа к чужим аккаунтам**; телефон публично не отображается.
- В «Настройках сезона» укажите реальные даты начала и конца. По умолчанию: 01.11.2026–30.11.2026.

## Важные правила

- Засчитывается **каждая отдельная покупка** от 400 ₽, совершённая по московскому времени между 21:00 и 09:00 (09:00 не включается). Вторая подтверждённая покупка в ту же ночь даст ещё +1, поскольку условие сформулировано как **30 покупок**, а не **30 разных дат**.
- Одна покупка на 800 ₽ всё равно даёт только +1.
- Покупку проверяет администратор и вводит вручную. **СмартШелл не подключён автоматически** — название «автоматически» относится к начислению после подтверждения в панели.
- Ошибочно подтверждённую **последнюю покупку** можно отменить из истории при условии, что соответствующий подарок ещё не выдан. Отмена записывается в журнал.
- Для безопасности рекомендуем обязательно указывать номер операции/чека из SmartShell: одинаковый номер система повторно не пропустит. Пока это поле необязательно для простоты первого запуска.
- Оплата пропуска отмечается администратором только после реальной оплаты.
- После достижения 30/30 больше покупок в сезоне не начисляется.
- При попадании в личный кабинет по секретной ссылке видны ник, прогресс, подарки и история сумм/времени, но не номер телефона. Ссылку нельзя публиковать.

## Публикация в интернете

Эта версия работает на Python и SQLite и подходит для тестового/внутреннего запуска. Для публичного домена нужен **сервер с постоянным диском, домен и HTTPS** (обычно VPS + Caddy/Nginx как reverse proxy). Не размещайте `data/` в публичной папке сайта.

Обязательно:
- Смените стартовый код администратора перед публикацией.
- Включите HTTPS и задайте `SETKA_HTTPS=1`, чтобы cookie авторизации передавалась только по HTTPS.
- Оставьте базу на постоянном диске и делайте резервные копии.
- Поставьте HTTPS reverse proxy и ограничьте доступ/частоту запросов на вход в админку.
- Заранее опубликуйте политику обработки персональных данных и получите необходимые согласия на номера телефонов; храните их только для учёта программы и не публикуйте.

### Запуск через Docker на сервере

```bash
# После настройки домена и HTTPS-прокси
export SETKA_ADMIN_CODE='ЗАМЕНИТЕ_НА_ДЛИННЫЙ_СЕКРЕТНЫЙ_КОД'
export SETKA_HTTPS=1
docker compose up -d --build
```

По умолчанию Docker открывает порт **8080 на 127.0.0.1**, чтобы его можно было безопасно проксировать наружу через HTTPS. Внешний доступ без прокси и HTTPS не рекомендуется.

## Что можно добавить в следующей версии

1. Проверку уникальных операций через официальную интеграцию SmartShell (если у клуба есть соответствующий доступ).
2. Роли для разных администраторов с разными логинами и журналом, кто именно подтвердил покупку.
3. Подтверждение телефона по SMS или Telegram для восстановления личной ссылки.
4. Управление призами через админ-панель, без правки `PRIZES` в `server.py`.
5. Публичные правила акции и страницу обработки персональных данных после согласования с владельцем клуба.
